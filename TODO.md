## 🔧 ТЕХНИЧЕСКИЙ ДОЛГ

### Архитектура
- Данные хранятся в LocalStorage - для продакшена нужна БД
- Нет разделения на окружения (dev/prod)
- Нет системы сборки (webpack/vite)
- Нет минификации JS/CSS
- Нет версионирования API

### Безопасность
- Нет валидации на сервере (только клиент)
- Нет защиты от XSS
- Нет защиты от CSRF
- Админка доступна без авторизации
- Нет rate limiting

### Производительность
- Все товары загружаются сразу
- Нет пагинации
- Нет кэширования
- Большие изображения загружаются без оптимизации
- Нет CDN для статики
